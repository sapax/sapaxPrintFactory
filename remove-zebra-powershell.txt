Using the app

Run it with the --uninstall flag from a command prompt in the folder containing the exe:

FakeZebraPrinter.exe --uninstall

This removes the Fake Zebra printer and the IP_127.0.0.1_9100 port. To set it up again, run the exe normally (without the flag) and it recreates both.

Manually, in admin PowerShell

powershell
Remove-Printer -Name "Fake Zebra"
Remove-PrinterPort -Name "IP_127.0.0.1_9100"

Optional: remove the driver too

The app leaves the “Generic / Text Only” driver installed, since Windows may use it for other printers. If you want a completely clean reset:

powershell
Remove-PrinterDriver -Name "Generic / Text Only"

If this says the driver is in use, another printer is still using it. Remove that printer first, or just leave the driver.
